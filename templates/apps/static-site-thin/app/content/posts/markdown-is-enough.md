Every few years a new editor promises rich blocks, embeds and collaboration. Every few years the notes written in it become hard to move. The markdown files from fifteen years ago still open.

## Structure you can see

Headings, lists, emphasis, links and code — that is the structure of almost every document worth reading, and markdown spells each one with a character you can type.

| Need      | Markdown      |
| --------- | ------------- |
| A heading | `## Title`    |
| Emphasis  | `*this*`      |
| A link    | `[text](url)` |
| Code      | backticks     |

## Everything else is a plugin

Tables, footnotes and task lists are extensions; use them when the renderer supports them and the text still reads without them.
